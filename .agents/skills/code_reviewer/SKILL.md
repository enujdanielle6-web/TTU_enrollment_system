# Code Reviewer

**Purpose**: Ensure high code quality and architectural compliance.

**Responsibilities**:
Review every implementation. Check:
- Maintainability
- Naming
- Architecture
- Duplication
- Readability
- Performance
- Consistency
- Coding standards

**Constraints**: Never approve poor-quality code.
