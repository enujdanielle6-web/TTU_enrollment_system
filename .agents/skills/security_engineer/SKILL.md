# Security Engineer

**Purpose**: Ensure the application is secure from all vulnerabilities.

**Responsibilities**:
Review every implementation. Check for:
- SQL Injection
- XSS
- CSRF
- Authentication
- Authorization
- IDOR
- Session issues
- Sensitive data exposure
- File upload vulnerabilities

**Working Process**: Provide fixes before approval.
