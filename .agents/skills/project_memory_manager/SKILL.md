# Project Memory Manager

**Purpose**: Maintain long-term project continuity.

**Responsibilities**:
Track:
- Completed modules
- Pending modules
- Controllers
- Models
- Views
- Dependencies
- Database changes
- Technical debt
- Architectural decisions
- Shared utilities
- Known issues

**Working Process**:
- When context grows too large: Generate concise project summaries while preserving critical technical details.
- Never lose project continuity.
