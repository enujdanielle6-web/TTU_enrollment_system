## 1. Forensic Analysis Overview

The `users` table contains exactly **20 columns**. It serves as the unified identity directory for Triple T University, accommodating applicants, registered students, academic faculty, administrative staff, and superadministrators.

### Classification Summary
- **SHARED / MULTI-DOMAIN (6 columns):** `id`, `first_name`, `last_name`, `email`, `student_number`, `role`, `permissions`
- **SHARED (3 columns):** `department`, `created_at`, `updated_at`
- **AUTHENTICATION (8 columns):** `password`, `email_verified`, `verification_code`, `verification_code_expires_at`, `reset_token`, `reset_token_expires_at`, `force_password_reset`, `is_active`
- **ENROLLMENT (2 columns):** `ttu_email`, `college_curriculum_id`
- **LMS (0 dedicated columns):** The LMS currently possesses **zero dedicated columns** in `users`; instead, it overloads shared authentication and identity fields.
- **LEGACY_OR_UNCLEAR (0 columns):** Every column has an identifiable operational purpose in the active codebase.

## 2. Column-by-Column Forensic Dossier

### 1. `id`
- **Datatype:** `INT(10) UNSIGNED NOT NULL AUTO_INCREMENT`
- **Default:** None
- **Constraints:** `PRIMARY KEY`
- **Purpose:** Unique surrogate identifier for every person in the institution.
- **Enrollment Usage:** Foreign key parent for `applications.user_id`, `health_records.user_id`, `student_assessments.user_id`, `payment_records.user_id`, `payment_records.cashier_id`, `scholarship_applications.user_id`, `scholarship_recipients.user_id`, `activity_logs.user_id`.
- **LMS Usage:** Foreign key parent for `lms_courses.faculty_user_id`, `lms_submissions.student_id`, `lms_submissions.graded_by`, `lms_quiz_attempts.student_id`, `lms_attendance_records.student_id`, `lms_announcements.author_user_id`.
- **Authentication Usage:** Stored in `$_SESSION['user_id']` and `$_SESSION['lms_user_id']`.
- **Files Reading:** `AuthController.php`, `LmsAuthController.php`, `LmsService.php`, `EnrollmentService.php`, `AssessmentService.php`, all controllers.
- **Files Writing:** Generated by MySQL engine on `INSERT` in `AuthController.php`, `SystemController.php`.
- **Session Dependency:** Yes (`$_SESSION['user_id']`, `$_SESSION['lms_user_id']`).
- **Classification:** `SHARED / MULTI-DOMAIN`

### 7. `student_number`
