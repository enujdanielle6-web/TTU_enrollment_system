# 00. SYSTEM OVERVIEW

## System Mission & Executive Scope
Triple T University (TTU) operates an integrated web-based educational management suite consisting of:
1. **The Enrollment System (Student Information System):** Manages admissions, applicant registration, document verification, clinic/medical review, curriculum management, section scheduling, tuition fee assessment, cashiering, and scholarships.
2. **The Learning Management System (LMS):** Powers digital coursework, digital module sharing, lecture materials, assignments, timed quizzes, attendance tracking, and grade calculation.

## Dual Academic Tracks
- **Higher Education (College):** Unit-based tuition calculation, collegiate semesters (1st, 2nd, Summer), academic degree programs (BSIT, BSCS, BSIS, BSHM), and 4-year progression.
- **Senior High School (SHS):** Fixed-voucher tuition templates, semesters, academic tracks/strands (STEM, ABM, HUMSS, TVL-ICT), and Grades 11–12.

## Key System Identifiers

- **Database Name:** `sia` (MariaDB / MySQL)
- **Primary Technology Stack:** Vanilla PHP 8.x, MariaDB, Apache (`mod_rewrite`), Bootstrap 5, Vanilla JS.
